Compare the same time window

The default is the last 28 days, excluding today. Choose a different date range inside the report. KPI changes compare the previous period of equal length. Percentage changes are relative changes; check the actual counts, especially with a small audience.

Explore attention and reach

Click a source in Acquisition quality to filter the analysis to that channel. Clear the chart filter to return to all traffic. Views per active user helps distinguish reach from repeated viewing; it is not reading time or a count of return visitors.
